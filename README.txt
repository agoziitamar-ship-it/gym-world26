GYM WORLD — installable PWA prototype

1. Extract this ZIP.
2. Upload the CONTENTS of the GYM_WORLD_PWA folder to an HTTPS static web host (for example GitHub Pages or Netlify).
3. Open the resulting HTTPS URL in Chrome on Android.
4. Chrome menu (three dots) > Add to Home screen > Install.

Important:
- Opening index.html as a local file does NOT enable PWA installation.
- This is an early prototype, not the complete planned game.
- Saves use this browser's localStorage only, not cloud accounts.
- Do not clear site data if you want to keep this prototype's save.
- If you previously played a file:// copy, its save does not transfer automatically.
- A publicly hosted URL may be visible to anyone who has the link.
